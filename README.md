# kevin9327

I find bugs in other people's code and send the fix. Mostly Rust, TypeScript and Python.

## How I work

1. **Reproduce** the bug on the project's current main branch, from the report or from reading the code.
2. **Write a failing test** that pins the bug down in the project's own test suite.
3. **Fix** it with the smallest change that makes the test pass, in the project's style.
4. **Verify**: the full suite, lint and type checks, and the other platforms the project supports where I can. Then I answer review comments until the maintainer is happy.
